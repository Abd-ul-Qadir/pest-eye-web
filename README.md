## Pest Eye | Crop Pest Identification System
🔗 **Live:** [pesteyee.netlify.app](https://pesteyee.netlify.app/)

**Description:** An AI-powered crop pest identification web application designed for **farmers and researchers**, built with React. It's hosted and deployed via **Netlify**.

**Tech Stack:**
| Layer | Technology |
|---|---|
| Frontend | React.js |
| Styling | SCSS, CSS |
| Deep Learning | PyTorch — EfficientNet-B0 |
| Backend | FAST API |
| Hosting/Deployment | Netlify |
